# 示例数据说明

## 文件说明

### file_A_source.csv（源数据文件）
包含员工的详细信息：
- 员工ID（主键）
- 姓名
- 部门
- 薪资
- 入职日期
- 绩效评分

### file_B_target.csv（目标文件）
包含员工的联系方式：
- 员工ID（主键）
- 姓名
- 邮箱
- 电话

## 测试场景

1. **主键列**：使用"员工ID"作为两个文件的匹配主键

2. **要补充的列**：从文件A选择"部门"、"薪资"、"绩效评分"补充到文件B

3. **预期结果**：
   - E001-E003, E005-E007, E010：匹配成功，数据被补充
   - E004, E008, E009：仅存在于文件A，不会出现在结果中
   - E011, E012：仅存在于文件B，补充列显示为NULL

## 使用步骤

1. 上传 `file_A_source.csv` 作为源数据文件(A)
2. 上传 `file_B_target.csv` 作为目标文件(B)
3. 选择"员工ID"作为两个文件的主键列
4. 勾选要补充的列：部门、薪资、入职日期、绩效评分
5. 点击处理，查看预览结果
6. 导出为CSV或Excel格式
